# 指尖花开（gesture-flower）

用摄像头识别手势，控制一朵粒子花：**握拳**时花朵收拢成花苞，**张开手掌**时花瓣向外绽放；花朵贴在掌心、跟着手掌移动和倾斜，五个指尖附近的花瓣粒子会被推开、打旋、发亮。

- 3D 渲染：Three.js 0.186（粒子形状、开合、卷曲都在 GLSL 顶点着色器里计算，约 2 万个粒子）+ UnrealBloom 泛光
- 手势识别：MediaPipe Tasks Vision 1.1 的 `HandLandmarker`（21 个关键点，`VIDEO` 模式，优先 GPU，不行自动退回 CPU）
- 原生 JavaScript ES Module，通过 import map 从 jsDelivr 加载依赖，不需要构建

## 运行

摄像头只能在安全上下文里使用：`http://localhost` 或 `https`。在本目录下启动任意静态服务器：

```console
python3 -m http.server 8080
# 或者 npx serve -l 8080
```

然后用 Chrome / Edge / Safari 打开 <http://localhost:8080>，点「开启摄像头」并允许权限。

- 首次加载需要联网：Three.js、MediaPipe 的 WASM（约 10 MB）和手部模型（约 7.8 MB）都从 CDN 下载，之后浏览器会缓存
- 没有摄像头也能玩：点「用鼠标体验」，或直接打开 <http://localhost:8080/?demo>。鼠标/手指就是一根「指尖」，按住 = 握拳
- 在手机上用：需要 https。比如电脑上用 `npx vite --host` 配合自签名证书，或部署到任何 https 静态托管

页面右上角可以隐藏摄像头背景、显示手部骨架（调试用）。

## 原理

**张开度**（`src/hand.js` 的 `opennessOf`）：用 `worldLandmarks`（以手为中心、单位米的 3D 坐标）计算，不受手离镜头远近和手掌朝向影响。

- 四指：指尖到手腕的距离 ÷ 掌指关节到手腕的距离，握拳约 1.0，张开约 2.0，线性映射到 0~1
- 拇指：拇指尖到食指根部的距离 ÷ 掌宽
- 两者加权（四指 0.82、拇指 0.18），再平滑，映射成花朵的开合目标

**跟随**（`src/main.js`）：

- 花朵锚在掌心（手腕与四个掌指关节的平均点），大小随掌长缩放，随手掌倾斜旋转
- 位置用 One Euro 滤波去抖
- 背景是镜像、调暗的摄像头画面，按 `object-fit: cover` 裁切；关键点用同样的换算映射到屏幕，所以花朵正好叠在你的手上
- 手短暂丢失 0.5 秒以内时，花朵保持原状

**花朵**（`src/flower.js`）：三层花瓣（10 + 8 + 6 片）、花心、花蕊、花粉。

- 每片花瓣是一条沿长度弯曲的弧面：`arc()` 对弯曲角做解析积分；轮廓是倒卵形，横向下凹
- 花苞时基部外鼓、尖端内扣，正好在中轴合拢；盛开时外翻、尖端下垂
- 外层先开、内层后开
- 开合由临界阻尼弹簧驱动，张开越快，粒子向外迸发越强
- 指尖交互在着色器里按世界坐标计算：推开、绕指尖打旋、变亮

## 调试参数

| 参数 | 作用 |
|---|---|
| `?demo` | 直接进入鼠标体验模式 |
| `?bloom=0.5` | 把开合固定在某个值（0 花苞 ~ 1 盛开），便于截图调参 |
| `?debug` | 把内部状态挂到 `window.__debug` |
