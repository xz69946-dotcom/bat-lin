# 指尖花开（gesture-flower）

一朵用手指触摸控制的 3D 粒子花，手机和电脑都能玩，不需要摄像头。

| 操作 | 效果 |
|---|---|
| **长按**（0.35 秒内不移动） | 花朵收拢成花苞，松手后重新绽放 |
| **双指**捏合 / 张开 | 连续控制开合：两指距离不超过屏幕短边的 12% 时全收，达到 62% 及以上时全开 |
| **滑动** | 手指就是指尖，附近的花瓣粒子会被推开、打旋、发亮 |
| 鼠标悬停（电脑） | 同「滑动」 |
| 什么都不做 | 7 秒后花朵自己像呼吸一样慢慢开合 |

- 3D 渲染：Three.js 0.186。约 2 万个粒子的形状、开合、卷曲都在 GLSL 顶点着色器里计算，再加 UnrealBloom 泛光
- 原生 JavaScript ES Module，通过 import map 从 jsDelivr 加载 Three.js，不需要构建

## 运行

在本目录下启动任意静态服务器：

```console
python3 -m http.server 8080
# 或者 npx serve -l 8080
```

然后打开 <http://localhost:8080>。首次加载要联网，从 CDN 下载 Three.js。

## 原理

**触摸**（`src/main.js`）：用 Pointer Events 统一处理手指和鼠标，舞台设了 `touch-action: none`，防止浏览器把手势当成滚动或缩放。

- 每根手指先记为「待定」：0.35 秒内移动不超过 12px 就判定为长按，超过就判定为滑动
- 两根手指同时按下时进入捏合模式，按两指距离算开合目标
- 最多 5 个触点作为「指尖」传进着色器

**花朵**（`src/flower.js`）：三层花瓣（10 + 8 + 6 片）、花心、花蕊、花粉。

- 每片花瓣是一条沿长度弯曲的弧面：`arc()` 对弯曲角做解析积分；轮廓是倒卵形，横向下凹
- 花苞时基部外鼓、尖端内扣，正好在中轴合拢；盛开时外翻、尖端下垂
- 外层先开、内层后开
- 开合由临界阻尼弹簧驱动，张开越快，粒子向外迸发越强
- 指尖交互在着色器里按世界坐标计算：推开、绕指尖打旋、变亮
- 系统开启「减少动态效果」时，关闭自转和迸发

## 调试参数

| 参数 | 作用 |
|---|---|
| `?bloom=0.5` | 把开合固定在某个值（0 花苞 ~ 1 盛开），便于截图调参 |
| `?debug` | 把内部状态挂到 `window.__debug` |
